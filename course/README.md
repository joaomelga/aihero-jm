# Course — Environment setup

Run the following to sync project state (if the `uv` CLI is available):

```bash
uv sync
```

Activate the Python virtual environment (using Bash / Git Bash on Windows):

```bash
source .venv/Scripts/activate
```

Notes:
- On Unix/macOS virtualenvs typically live under `.venv/bin/activate`.
- On PowerShell use: `.venv\\Scripts\\Activate.ps1`.
